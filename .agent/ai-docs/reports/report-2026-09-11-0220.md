## 5. Detailed Task Changelogs Archive

### task-01-tool-data-models: Tool Data Models & Item Integration
- Defined enums ToolType, ToolTier, and ToolAreaPattern.
- Implemented [System.Serializable] struct ItemToolData with pattern dimension, stamina cost, and static factory defaults (DefaultHoe, DefaultWateringCan).
- Created interface IToolItemReceiver with BindItemData(Item item).
- Integrated ToolData property and serialized _toolData field into Item ScriptableObject under [Header(Tool Upgrade Data)].

### task-02-farming-grid-expansion: Farming Grid Coordinate Expansion
- Extended IFarmingGrid contract with CellSize, WorldToCell(Vector3), and GetCellCenterWorld(Vector3Int).
- Implemented coordinate conversion methods and CellSize property on FarmingGrid delegating directly to Unity's underlying Grid asset.

### task-03-tool-area-calculator: Pure Service: Tool Area Calculator
- Implemented GetCardinalFacingDirection(Vector3) to map 3D view/forward vectors into grid cardinal directions (+Z, -Z, +X, -X).
- Implemented CalculatePatternCells(...) supporting Single, ForwardLine, and CenteredSquare multi-tile patterns using pre-allocated zero-GC buffer array.
- Implemented GetMaxTileCount(...) buffer sizing helper.

### task-04-multi-preview-system: Multi-Cell Hologram Preview System
- Defined TilePreviewData struct and MultiPreviewingEvent struct on EventBus.
- Updated PlacementPreviewer to maintain a pooled list of holograms using LeanPool.
- Implemented OnMultiPreviewing handler rendering per-cell validity and position across all tiles in the active tool area pattern.
- Retained OnPreviewing as a backwards-compatible single-tile wrapper forwarding to OnMultiPreviewing.

### task-05-farming-tool-base-binding: Tool Item Binding & FarmingToolBase Integration
- Injected item binding into PlayerHandVisualizer.SpawnItemModel querying IToolItemReceiver on spawned models.
- Updated FarmingToolBase to implement IToolItemReceiver, store ItemToolData toolData, and allocate reusable cell/preview buffers.
- Added RunMultiPreviewUpdate(...) to calculate multi-tile footprints, evaluate per-cell grid validity, and raise MultiPreviewingEvent without runtime GC allocation.

### task-06-upgraded-hoe: Upgraded Hoe Straight-Line Tilling
- Updated Hoe to use RunMultiPreviewUpdate for multi-tile previewing in HoeState.Farming.
- Updated PrimaryAction to calculate pattern tiles based on player cardinal direction and store valid candidate cells into _pendingTillingCells.
- Updated OnTillingAnimationFinish to iterate through all pending cells and till them on impact event.

### task-07-upgraded-watering-can: Upgraded Watering Can Square Watering
- Updated WateringCan to use RunMultiPreviewUpdate for multi-tile previewing in WaterCanState.Farm.
- Updated PrimaryAction to gather centered NxN square cells (CenteredSquare) and store waterable tiles into _pendingWateringCells.
- Updated OnWaterinAnimationFinished to iterate through all pending cells and hydrate them on animation finish event.

### task-08-tool-documentation: Tool Subsystem Documentation & User Manual
- Authored subsystem documentation following Rule 16 of the architecture guide.
- Included technical architecture overview, component/event reference table, and a step-by-step designer user manual for creating and tuning upgraded tool ScriptableObjects in Unity.
